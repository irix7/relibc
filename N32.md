# IRIX 7 n32 port branch

This branch carries the demonstrated n32 big-endian port of relibc used for the
IRIX 7 POSIX/C ABI layer.

- Upstream base: `841d29c0c16dfa5c170f9208e7a6f93696802726`
- Branch: `irix7-n32`
- Port report: [`irix7-n32/README.md`](irix7-n32/README.md)
- Patch set: [`irix7-n32/patches`](irix7-n32/patches)

The port was validated on `mips64-linux-gnuabin32` under `qemu-mipsn32` with
`hello`, `printf`, `__thread` TLS, `setjmp`/`longjmp`, and pthread/TLS.  It is a
research branch, not yet the IRIX 7 native PAL: the Linux `sc` syscall backend
still has to be replaced by the IRIX capability ABI.

Do not treat this as production-ready.  See the report for the static-only,
signal, long-double and syscall-width limitations.
